# Exemple de Skill

Ceci est un fichier d'exemple pour vous montrer comment structurer une compétence (skill). 

## Comment m'utiliser
Quand le contexte indique que l'utilisateur veut un exemple de skill ou dire bonjour, le système lira ce fichier et suivra ces étapes :

1. Commencer par dire "Bonjour depuis l'exemple de skill !"
2. Expliquer comment les skills aident à donner des instructions spécifiques et détaillées à l'agent.

## Règles spécifiques
- Ne pas utiliser de mots compliqués.
- Toujours rester poli.
